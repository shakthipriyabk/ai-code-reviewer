# AI Code Reviewer

An AI-powered code review application built using Java and Spring Boot.

## Features

- Automated code review
- AI-generated suggestions and feedback
- Clean web interface
- REST API integration
- Maven-based project structure

## Tech Stack

- Java 21
- Spring Boot
- Maven
- HTML/CSS/JavaScript
- Gemini API
